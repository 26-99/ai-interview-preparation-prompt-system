## 4. Sample Technical Questions
**Q: What is OOP in Java?**

OOP stands for Object-Oriented Programming. 
It organizes programs using classes and objects. 
Its four main principles are encapsulation, inheritance, polymorphism and abstraction.

**Q: What is a REST API?**

A REST API allows applications to communicate over HTTP using methods such as GET, POST, PUT and DELETE.
